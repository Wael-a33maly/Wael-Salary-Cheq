# دليل رفع وتشغيل المرحلة 1 على استضافة Hostinger

## نظرة عامة
المرحلة 1 تحتوي على:
1. **سكربت التنصيب الآلي (`install/index.php`)**: يقوم بإنشاء الجداول وحساب المدير وتوليد ملف الاتصال وقفل التنصيب بملف `install.lock`.
2. **مخطط قاعدة البيانات الكامل (`install/schema.sql`)**: مهيأ لجميع الجداول الثمانية (users, settings, branches, departments, employees, monthly_records, payslips, audit_log) بترميز `utf8mb4_unicode_ci`.
3. **ملف الاتصال التلقائي (`config/db.php`)**: يتم إنشاؤه آلياً بواسطة التنصيب، مع دعم PDO واستعلامات Prepared Statements.
4. **النواة الأمنية (`core/auth.php` و `core/audit.php` و `core/helpers.php`)**: إدارة الجلسات، تشفير bcrypt، حماية CSRF، سجل التدقيق، ودوال الدينار الكويتي KWD.
5. **شاشة تسجيل الدخول (`login.php`) وتسجيل الخروج (`logout.php`)** ولوحة التحكم المبدئية (`index.php`).

---

## خطوات التثبيت على استضافة Hostinger:

### الخطوة 1: إنشاء قاعدة بيانات MySQL على Hostinger
1. ادخل إلى لوحة تحكم **Hostinger hPanel**.
2. توجّه إلى قسم **Databases (قواعد البيانات)** -> **MySQL Databases**.
3. أنشئ قاعدة بيانات جديدة:
   - اسم قاعدة البيانات (مثال: `u123456_payroll`)
   - اسم المستخدم (مثال: `u123456_payadmin`)
   - كلمة المرور (اختر كلمة مرور قوية واحتفظ بها)
4. اضغط **Create (إنشاء)**.

### الخطوة 2: رفع الملفات إلى الدومين الفرعي (Subdomain)
1. من لوحة Hostinger، اذهب إلى **File Manager (مدير الملفات)**.
2. ادخل إلى مجلد الدومين الفرعي الخاص بك، عادة يكون في:
   `/public_html/subdomain/`
3. ارفع محتويات مجلد `public_html` بالكامل بحيث يكون الهيكل:
   ```text
   /public_html/subdomain/
   ├── install/
   │   ├── index.php
   │   └── schema.sql
   ├── config/
   │   └── db.php.example
   ├── core/
   │   ├── auth.php
   │   ├── audit.php
   │   └── helpers.php
   ├── uploads/
   ├── login.php
   ├── logout.php
   ├── index.php
   └── .htaccess
   ```
4. تأكد من أن تصريح مجلد `config` و `uploads` و `install` هو `755` لتتمكن السكربتات من الكتابة.

### الخطوة 3: تشغيل سكربت التنصيب
1. افتح المتصفح وتوجه إلى الرابط:
   `https://subdomain.yourdomain.com/install/`
2. املأ بيانات قاعدة البيانات التي أنشأتها في الخطوة 1:
   - Host: `localhost`
   - Database Name: اسم القاعدة بالكامل
   - DB User: اسم المستخدم
   - DB Password: كلمة المرور
3. حدد بيانات حساب المدير العام (Super Admin):
   - اسم المستخدم (مثل: `admin`)
   - كلمة المرور (6 خانات أو أكثر)
   - اسم المدير
4. حدد اسم الشركة ومعامل الإضافي وأيام تنبيه الإقامة.
5. اضغط **«بدء التنصيب التلقائي وإنشاء الجداول»**.

### الخطوة 4: التحقق والاختبار
- سيقوم السكربت بالاتصال، إنشاء الجداول الثمانية، تشفير كلمة المرور بـ bcrypt، إنشاء `config/db.php`، وإنشاء ملف `install.lock` لمنع إعادة التنصيب.
- اضغط على زر **الانتقال لتسجيل الدخول** وسجل الدخول بالحساب الذي أنشأته.
- ستفتح لك لوحة التحكم وتظهر رسالة نجاح المرحلة الأولى مع إحصائيات الجداول وجلسة العمل وسجل التدقيق.
