# نظام إدارة الرواتب المتعدد الفروع بالدينار الكويتي (KWD)
## دليل الرفع والتنصيب والتشغيل على استضافة Hostinger المشتركة (Shared Hosting / Subdomain)

---

### 🌟 نظرة عامة على النظام
نظام مالي وإداري متكامل مبني بلغة **PHP 8.2+** وقاعدة بيانات **MySQL 8.0+** مع واجهات **Bootstrap 5 RTL** ودعم كامل للخط العربي الرسمي **Cairo**.
مخصص للشركات والمؤسسات ذات الفروع المتعددة في دولة الكويت، مع اعتماد الدقة المالية الكاملة بـ **3 خانات عشرية** (`DECIMAL(10,3)`) وتطبيق قاعدة التقريب النقدي للأسفل (`Floor to 0.050 KWD`).

### 🚀 خطوات التنصيب والتشغيل على Hostinger

#### الخطوة 1: إنشاء قاعدة بيانات MySQL
1. سجل الدخول إلى لوحة تحكم **Hostinger hPanel**.
2. توجه إلى قسم **قواعد البيانات (Databases) &larr; إدارة MySQL**.
3. أنشئ قاعدة بيانات جديدة:
   - اسم قاعدة البيانات: `u123456_payroll`
   - اسم المستخدم: `u123456_admin`
   - كلمة المرور: احفظها جيداً.
4. الخادم الداخلي هو دائماً: `localhost`.

#### الخطوة 2: رفع الملفات عبر مدير الملفات (File Manager)
1. في hPanel، توجه إلى **الملفات (Files) &larr; إدارة الملفات (File Manager)**.
2. ادخل إلى مجلد الدومين الفرعي الخاص بك (مثال: `public_html/payroll/` أو `public_html/`).
3. ارفع ملف الأرشيف المضغوط `payroll_system_kwd_production.zip`.
4. اضغط بالزر الأيمن على الملف واختر **استخراج (Extract)** داخل نفس المجلد.
5. تأكد من أن مجلد `config` ومجلد `install` يحملان تصريح الكتابة `755` أو `775`.

#### الخطوة 3: تشغيل معالج التنصيب الآلي
1. افتح متصفحك وتوجه إلى رابط المعالج:
   ```
   https://subdomain.yourdomain.com/install/
   ```
2. سيقوم المعالج تلقائياً بفحص بيئة التشغيل:
   - إصدار PHP 8.1 أو أحدث (موصى به PHP 8.2).
   - توفر ملحقات PDO, PDO_MYSQL, MBSTRING, JSON, OPENSSL.
   - التحقق من صلاحيات الكتابة.
3. أدخل بيانات الاتصال بقاعدة البيانات (Host, DB Name, User, Password).
4. أدخل بيانات المدير العام للنظام (Super Admin Username, Full Name, Password).
5. أدخل إعدادات الشركة الأولية (اسم الشركة، معامل الإضافي: 1.25، أيام تنبيه الإقامة: 60).
6. اضغط **بدء التنصيب والتثبيت الآلي**.

#### الخطوة 4: القفل الأمني التلقائي
- يقوم المعالج بإنشاء ملف `install/install.lock` لمنع أي محاولة لإعادة تثبيت النظام أو الكتابة فوق البيانات.
- يقوم بإنشاء ملف `config/db.php` المشفر الذي يحتوي على اتصال PDO السري.
- ملف `.htaccess` المرفق يمنع أي وصول خارجي لملفات الإعدادات ومجلد `install`.

#### الخطوة 5: تسجيل الدخول والبدء
- بعد انتهاء التنصيب، اضغط على زر **الانتقال لتسجيل الدخول** أو توجه إلى:
  ```
  https://subdomain.yourdomain.com/login.php
  ```
- سجل الدخول باسم المستخدم وكلمة المرور التي حددتها في معالج التنصيب.

### 📐 القواعد والمعادلات المالية المعتمدة

1. **حساب أجر اليوم والساعة بدقة التقويم الفعلي:**
   - $\text{أجر اليوم} = \frac{\text{الراتب الأساسي}}{\text{أيام الشهر الفعلية (28 أو 29 أو 30 أو 31)}}$
   - $\text{أجر الساعة} = \frac{\text{أجر اليوم}}{\text{ساعات العمل اليومية}}$

2. **الاستقطاعات والإضافي:**
   - خصم أيام الغياب = $\text{أيام الغياب} \times \text{أجر اليوم}$
   - خصم ساعات الغياب = $\text{ساعات الغياب} \times \text{أجر الساعة}$
   - أجر ساعة الإضافي = $\text{أجر الساعة} \times \text{معامل الإضافي (افتراضياً 1.25)}$
   - مبلغ الإضافي = $\text{ساعات الإضافي} \times \text{أجر ساعة الإضافي}$
   - صافي الراتب المستحق = $\text{الراتب الأساسي} - \text{استقطاع الغياب} - \text{استقطاع السلفة} + \text{مبلغ الإضافي}$

3. **التقريب النقدي للأسفل (Floor to 0.050 KWD):**
   - المبلغ النقدي المستحق الخام = $\text{صافي الراتب} - \text{المبلغ المحول بنكياً}$
   - يحول المبلغ النقدي إلى فلس صحيح: $\text{fils} = \text{round}(\text{rawCash} \times 1000)$
   - يستبعد باقي القسمة على 50 فلس: $\text{fils} = \text{fils} - (\text{fils} \pmod{50})$
   - المبلغ النهائي المسلم نقداً للموظف: $\text{finalCash} = \frac{\text{fils}}{1000}$
   - وفر التقريب لصالح الخزينة = $\text{rawCash} - \text{finalCash}$

### 🛡️ ميزات الأمان المتقدمة
- **تشفير كلمات المرور:** باستخدام خوارزمية `PASSWORD_BCRYPT` الصارمة.
- **الحماية من الهجمات الغاشمة (Rate Limiting):** قفل تلقائي للحساب بعد 5 محاولات فاشلة لمدة 15 دقيقة مسجلة في قاعدة البيانات.
- **الحماية من CSRF:** توكن فريد لكل جلسة يتم التحقق منه في كافة طلبات POST.
- **حماية الجلسات والكوكيز:** تفعيل `HttpOnly` و `SameSite=Strict` و `Secure`، وتجديد معرف الجلسة آلياً `session_regenerate_id(true)` عند الدخول.
- **سجل التدقيق الشامل (Audit Trail):** تسجيل كل عملية تعديل أو إضافة أو حذف مع تفاصيل الحقول القديمة والجديدة بصيغة JSON مع عنوان IP ورقم المستخدم.
