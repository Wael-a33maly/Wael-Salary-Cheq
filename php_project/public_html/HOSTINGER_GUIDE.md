# دليل الرفع والتنصيب خطوة بخطوة على استضافة Hostinger

هذا الملف مخصص لمسؤولي النظام ومديري تقنية المعلومات لرفع وتشغيل نظام الرواتب الكويتي متعدد الفروع على استضافة هوستنجر (Hostinger Shared / Cloud Hosting).

---

## 1. متطلبات الاستضافة
- بيئة تشغيل: **PHP 8.1 أو PHP 8.2** (مفعلة تلقائياً في Hostinger).
- قاعدة بيانات: **MySQL 8.0+** أو **MariaDB 10.5+**.
- ملحقات PHP المطلوبة (مفعلة افتراضياً):
  - `pdo` و `pdo_mysql`
  - `mbstring`
  - `json`
  - `openssl`
  - `gd` (لرفع ومعالجة الشعار)

---

## 2. خطوات تجهيز قاعدة البيانات في Hostinger hPanel
1. افتح لوحة تحكم الاستضافة في Hostinger: `https://hpanel.hostinger.com/`.
2. من القائمة الجانبية، اختر **قواعد البيانات (Databases) &larr; إدارة MySQL**.
3. في نموذج "إنشاء قاعدة بيانات MySQL جديدة":
   - **اسم قاعدة البيانات:** أدخل اسماً مناسباً، مثلاً `payroll`.
   - **اسم مستخدم قاعدة البيانات:** مثلاً `dbadmin`.
   - **كلمة المرور:** اختر كلمة مرور قوية واحتفظ بها.
4. اضغط على زر **إنشاء (Create)**.
5. لاحظ اسم القاعدة الكامل واسم المستخدم (مثل `u123456789_payroll` و `u123456789_dbadmin`).

---

## 3. رفع ملفات النظام
1. حمّل ملف الحزمة الكاملة `payroll_system_kwd_production.zip`.
2. من لوحة تحكم hPanel، انتقل إلى **الملفات (Files) &larr; مدير الملفات (File Manager)**.
3. افتح مجلد الدومين الفرعي (Subdomain) أو المجلد الرئيسي:
   - مسار الدومين الفرعي: `domains/yourdomain.com/public_html/subdomain_name/`
   - أو المجلد العام: `public_html/`
4. اضغط على زر **رفع (Upload) &larr; File** واختر ملف ZIP.
5. بعد اكتمال الرفع، انقر بالزر الأيمن على الملف واختر **استخراج (Extract)**، وحدد نفس المجلد الحالي كوجهة.
6. يمكنك حذف ملف الـ ZIP بعد فك الضغط لتوفير المساحة.

---

## 4. تشغيل معالج التنصيب الآلي
1. افتح متصفحك وتوجه إلى الرابط:
   ```
   https://subdomain.yourdomain.com/install/
   ```
2. تحقق من ظهور جميع متطلبات النظام بالعلامة الخضراء (✓ متوافق).
3. اضغط على زر **متابعة لإعداد قاعدة البيانات**.
4. أدخل البيانات المسجلة من الخطوة 2:
   - **خادم القاعدة (Database Host):** اتركه `localhost`.
   - **اسم القاعدة (Database Name):** مثلاً `u123456789_payroll`.
   - **اسم المستخدم (Database User):** مثلاً `u123456789_dbadmin`.
   - **كلمة المرور (Database Password):** كلمة المرور التي عينتها.
5. اضغط على **اختبار الاتصال والمتابعة**.
6. في الخطوة الثالثة، أنشئ حساب المدير العام (Super Admin):
   - اسم المستخدم (للدخول).
   - الاسم الكامل ثلاثي.
   - كلمة المرور وتأكيدها.
   - اسم الشركة الرسمي.
   - معامل ساعات العمل الإضافي (افتراضياً 1.25).
   - أيام التنبيه لانتهاء الإقامة (افتراضياً 60 يوماً).
7. اضغط على **بدء التنصيب التلقائي وإنشاء الجداول**.

---

## 5. الحماية التلقائية بعد التنصيب
- سيقوم المعالج بإنشاء ملف `install/install.lock` تلقائياً لمنع أي تلاعب أو إعادة تنصيب.
- سيتم تشفير إعدادات الاتصال وحفظها في `config/db.php`.
- يتم حظر الوصول لملف `.sql` وملفات الإعدادات عبر `.htaccess`.

---

## 6. تسجيل الدخول اليومي
- توجه إلى رابط تسجيل الدخول:
  ```
  https://subdomain.yourdomain.com/login.php
  ```
- استخدم بيانات حساب المسؤول التي أنشأتها للبدء في إدارة الفروع والموظفين ومسير الرواتب الشهري والتقارير.
